# Film source

`runway-commercial-original.mov` is the untouched master for the homepage film. It is **not committed** (see `.gitignore`); keep your own backup.

| | |
|---|---|
| Origin | Runway-generated commercial, edited in CapCut, supplied by the owner on 2026-10-30 |
| Format | 1920×1080, 60 fps, H.264 High, BT.709, AAC stereo, 23.53 s, 28.6 MB |
| SHA-256 | see `SHA256SUMS` (`sha256sum -c SHA256SUMS` verifies it) |

Web versions in `public/media/film/` are generated from this file by `scripts/encode-film.sh`. Never edit the master; re-run the script instead.

The footage shows a Mercedes-AMG GT. The site must not use Mercedes branding or imply any partnership or endorsement. Trademark review is required before public launch.
